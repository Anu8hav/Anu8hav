## About

I build full-stack apps with TypeScript and Next.js, with some Python on the side. Most of my time right now goes into SchoolSync, a management platform for schools running on spreadsheets and WhatsApp. I run Arch with Hyprland, and this month I've spent more hours on my dotfiles than on application code — no regrets.

## Projects

### SchoolSync

A school management platform handling enrollment, attendance, scheduling, and admin workflows — built for small-to-mid schools with no dedicated software. The harder part isn't the CRUD, it's modeling recurring schedules and attendance exceptions without the data model turning into a mess.

`TypeScript` `Next.js` `Prisma` `PostgreSQL`

[Source](https://github.com/Anu8hav/SchoolSync) · Demo: in progress

### NJ Design Studio

A portfolio and inquiry-management site for an architecture studio. Next.js App Router with Clerk handling auth and a database-backed project gallery, built so the client can update work samples without touching code.

`TypeScript` `Next.js` `Clerk`

[Source](https://github.com/Anu8hav/NJ-Design-Studio)
